# M7 — analiza danych przejazdów

M7 dodaje deterministyczną analizę zakończonych logów M5. Surowy CSV jest czytany
tylko do odczytu; przed analizą sprawdzany jest manifest i SHA-256 `raw.csv`.
Uszkodzenie lub nieciągła numeracja rekordów zatrzymuje analizę zamiast tworzyć
częściowy raport.

Raport zawiera czas, dystans, pełne zatrzymania i ich czas, zdarzenia hamowania,
przybliżony koszt hamowania, przyspieszenia, średnią i maksymalną prędkość,
przejazdy na zielonym, przyjazdy na czerwonym, średni błąd przewidywanego czasu
przekroczenia oraz zgodność z wydanym celem prędkości. `estimated_braking_energy`
jest wskaźnikiem z próbek prędkości, nie pomiarem energii fizycznej. Brak GPS,
headingu albo celu pozostaje brakiem danych.

Można porównać dwa zakończone logi (baseline i GreenWave). Raport zwraca pełne
metryki obu przejazdów oraz delty. Delta opisuje różnicę między zapisami i nie
jest dowodem przyczynowości; porównywane przejazdy powinny mieć ten sam korytarz,
kierunek i porównywalne warunki.

API udostępnia `GET /api/analysis/<run_id>` oraz
`GET /api/analysis/compare?baseline=<id>&greenwave=<id>`. Panel pozwala wybrać
zakończony zapis i wyświetlić raport JSON. Analiza nie zmienia logu i nie uczy
jeszcze modelu. Statystyka relacji między obserwacjami i kalibracja predykcji
pozostają kolejnym rozszerzeniem.
